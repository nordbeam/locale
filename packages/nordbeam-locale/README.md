# nordbeam-locale

The command-line entry point of [Nordbeam Locale](https://github.com/nordbeam/locale)
for `npx`:

```sh
npx nordbeam-locale init --framework vite-react
```

It runs the CLI of [`@nordbeam/locale`](https://www.npmjs.com/package/@nordbeam/locale)
at the same version. In a project, install `@nordbeam/locale` itself; it provides
the same `nordbeam-locale` command along with the compiler and framework adapters.
