# Nordbeam Locale documentation

Nordbeam Locale targets React, Next.js, TanStack Start, Vue, Svelte, Solid, and plain TypeScript
applications. This documentation is organized by the job you are trying to
complete:

## Start here

- [README](../README.md): install, choose your framework, and the everyday
  workflow.
- [Guide](GUIDE.md): the features the README leaves out, with a table of contents.
  Covers selection, scopes, artifacts, the client and React adapters, translation
  workflows, migrations, the persistent cache, and tooling.
- [Cookbook](COOKBOOK.md): copyable recipes for switching locales, dates and
  currency, rich text, testing, and CI.

## Integrate

- [Next.js](NEXTJS.md): App Router, locale middleware and its matcher, server and
  client boundaries, and scopes.
- [TanStack Start](reference/tanstack-start.md): the router rewrite, request
  middleware, server function locale, and the language switcher.
- [Editor support](EDITOR.md): JSON schemas, the VS Code extension, and the
  development inspector.
- [Migration](MIGRATION.md): catalog, source, and project migrations from other
  i18n libraries.
- [Agent-first tooling](AGENT_TOOLING.md): how coding agents and MCP clients drive
  the CLI. The contract itself is in [agent](reference/agent.md).
- [Error and diagnostic codes](reference/errors.md): every code, its exit status,
  and its fix. `nordbeam-locale explain <CODE>` prints the same entries.
- [Package reference](reference/README.md): one page for every public export.
